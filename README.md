# jiuyou-panel-journal

本仓库用于归档和发布多个独立的 HTML 页面，主要面向日常浏览中产生的各种静态内容。

## 项目简介

jiuyou-panel-journal 是一个纯粹的 HTML 页面存档仓库。所有页面均为独立、自包含的静态文件，不依赖后端服务或特定域名。本仓库仅作为存放和展示这些页面的场所，不提供任何形式的商业服务或内容推荐。

## 目录说明

```
.
├── index.html          # 仓库入口页，列出所有已归档的页面链接
├── pages/              # 存放各独立 HTML 页面的子目录
│   ├── page-001.html
│   ├── page-002.html
│   └── ...
└── README.md           # 本文件
```

- `index.html`：仓库主页，可在此查看所有归档页面的索引。
- `pages/`：所有归档的 HTML 页面均放置在此目录下，文件名按顺序编号，便于管理。

## 页面归档说明

- 每个归档页面均为独立 HTML 文件，样式、脚本均内嵌或通过相对路径引用。
- 页面内容可能包含文字、图片、链接等常见元素，但不涉及任何具体网站或商业推广。
- 本仓库不接受任何形式的投稿或第三方提交，所有页面均来自维护者自行整理。

## 维护说明

- 本仓库不定期更新，新增页面的编号将延续现有顺序。
- 已归档的页面原则上不做修改，如有必要（如修复显示问题）会注明变更记录。
- 本仓库不提供 issue 或 pull request 的讨论功能，仅作为静态页面存放使用。

## 许可

本仓库内容仅用于个人存档与展示，不开放任何形式的商业使用或再分发。如需引用，请注明出处。
